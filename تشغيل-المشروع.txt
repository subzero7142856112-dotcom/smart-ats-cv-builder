========================================
  Smart ATS CV Builder — خطوات التشغيل
========================================

المتطلبات: Node.js نسخة 18 أو أحدث.

(1) افتح التيرمنال جوه فولدر المشروع ده، وثبّت الباكدجات:
        npm install

(2) جرّب الواجهة بس (من غير الذكاء الاصطناعي):
        npm run dev
    افتح الرابط اللي هيظهرلك (عادة http://localhost:5173).
    التطبيق هيشتغل بالكامل؛ أزرار AI هتقول "الباك إند مش متاح" وده طبيعي.

(3) عشان تشغّل الذكاء الاصطناعي كمان (الواجهة + الـ API مع بعض):
    - انسخ ملف .env.example وسمّيه .env واملا فيه:
          AI_API_KEY   = مفتاح المزوّد بتاعك (سرّي)
          AI_PROVIDER  = openai أو claude أو gemini أو groq أو openrouter
          AI_MODEL     = اسم الموديل (مثلاً gpt-4o-mini)
    - ثبّت أداة Vercel مرة واحدة:
          npm i -g vercel
    - شغّل:
          vercel dev

(4) النشر على الإنترنت (Vercel):
    - ارفع المشروع على GitHub (من غير ملف .env أبداً).
    - في Vercel: Settings → Environment Variables، ضيف:
          AI_API_KEY / AI_PROVIDER / AI_MODEL
    - اعمل Deploy. ملفات api/ هتتحول لـ serverless functions تلقائياً.

ملاحظة أمان: المفتاح السرّي يفضل في متغيرات البيئة على السيرفر فقط،
ومينفعش يكون في كود الواجهة. المتغيرات اللي تبدأ بـ VITE_ تظهر في المتصفح.
